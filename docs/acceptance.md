## 具体边界

- 原三款工具的业务、账号、实际更新与卸载仍归原软件。本轮验证进入其管理入口，不把入口打开写成更新或卸载成功。
- MediaFlow 原 `0.4.1-dev.48` 安装器在该干净 VM 的中文安装路径创建快捷方式失败；同一程序在更长的英文加空格路径通过。报告保留原失败证据。建议先选择英文安装路径；中文共享工作空间与 HyperFrames 全流程已通过。
- Studio 提供源码编辑、预览、检查和导出；上游完整可视化时间线编辑器尚未移植。
- 工具依赖独立性验证采用 System32-only PATH、包内绝对运行路径和实际进程取证。CI 外层验证器使用宿主工具，不把它描述为未预装任何程序的 Windows 映像。
- 断网验收真实阻断组件程序的非回环连接，保留本地预览和 CI 控制连接；四条临时规则全部移除，原有防火墙策略未变。
- 发行包未签名。未验证的系统级 DPI / 交互行为不记为通过。
